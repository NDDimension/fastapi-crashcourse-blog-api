## 🚀 **FastAPI — Quick Obsidian Notes**

### 📡 **What is an API?**

- **API** = _Application Programming Interface_ → A contract that allows software to communicate with other software.
    
- **Web APIs** typically use **HTTP** and **JSON**.
    
- **REST-style basics**:
    
    - **Verbs**:  
        `GET` (read), `POST` (create), `PUT/PATCH` (update), `DELETE` (remove)
        
    - **Status Codes**:  
        `200 OK`, `201 Created`, `400 Bad Request`, `401 Unauthorized`,  
        `404 Not Found`, `422 Unprocessable Entity`, `500 Server Error`
        
- Core Concepts:  
    **Endpoints**, **Request/Response**, **Headers**, **Query Params**,  
    **Path Params**, **Request Body**, **Authentication**
    

> [!note] **Mental model**  
> Expose resources (e.g., `users`, `items`) via routes. Clients exchange JSON via HTTP and rely on status codes for context.

---

### ⚡ **What is FastAPI?**

- A **modern**, **high-performance** Python web framework for building APIs.
    
- Built on:
    
    - **Starlette** → ASGI toolkit, handles fast I/O
        
    - **Pydantic** → Data validation & serialization using type hints
        
- Core strengths:
    
    - ⚡ Speed
        
    - 🧰 Developer productivity
        
    - 🔒 Type safety
        
    - 📜 Auto-generated documentation
        

---

### 🌟 **Core Features**

- **Type-driven** request parsing & validation using **Pydantic models**
    
- **Auto-generated documentation**:
    
    - Swagger UI → `/docs`
        
    - ReDoc → `/redoc`
        
    - OpenAPI schema → `/openapi.json`
        
- **Async-first** via ASGI for high concurrency
    
- **Dependency Injection** with `Depends()` for clean, testable code
    
- Built-in:
    
    - Security tools (OAuth2, JWT)
        
    - CORS & middleware
        
    - Background tasks, WebSockets, lifecycle events
        
    - File & form handling
        
- Clear, human-readable **error messages** for validation issues
    

> [!tip]  
> Use `response_model` to shape output and automatically hide internal fields in the docs.

---

### 🧠 **Framework Overview**

- Create an app using: `FastAPI()`
    
- Declare routes with decorators: `@app.get()`, `@app.post()`, etc.
    
- Define data schemas using `Pydantic`'s `BaseModel` (auto-validates + generates docs)
    
- Use `APIRouter` to modularize endpoints
    
- Add cross-cutting logic via **middlewares**, **dependencies**, **lifespan events**

### 🧪 **Minimal Example**

#### 💻 Bash

```bash
# Install (recommended)
pip install "fastapi[standard]"

# Run the app
uvicorn app.main:app --reload
```

#### 🐍 Python

```python
# app/main.py
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI(title="My API", version="1.0.0")

class Item(BaseModel):
    id: int
    name: str

@app.get("/")
async def root():
    return {"message": "Hello FastAPI"}

@app.post("/items", status_code=201)
async def create_item(item: Item):
    return item
```

- Access docs:  
    🔗 [http://localhost:8000/docs](http://localhost:8000/docs)  
    🔗 [http://localhost:8000/redoc](http://localhost:8000/redoc)

### 🧩 **Key Concepts Cheat-Sheet**

| Concept              | Example                           |
| -------------------- | --------------------------------- |
| Path Params          | `/users/{user_id}`                |
| Query Params         | `/items?limit=10&search=abc`      |
| Request Body         | Pydantic models                   |
| Response Models      | `response_model=YourModel`        |

### 🔐 **Security & Authentication (High-Level)**

- Use **OAuth2 with Password Flow + JWT** for secure login/session
    
- Use `Depends()` to inject `current_user`, permissions, etc.
    
- Enable **CORS** for browser-based frontend clients
    

---

### ⚙️ **ASGI vs WSGI**

| Feature       | ASGI               | WSGI            |
| ------------- | ------------------ | --------------- |
| Async Support | ✅ Yes              | ❌ No            |
| WebSockets    | ✅ Yes              | ❌ No            |
| Concurrency   | ✅ High             | ⚠️ Limited      |
| Server        | Uvicorn, Hypercorn | Gunicorn, uWSGI |

- FastAPI is built for **ASGI**, making it suitable for modern, real-time applications.

### 🧱 **Common Gotchas**

- Use **async DB drivers** (e.g., `SQLAlchemy 2.0 async`, `asyncpg`)  
    → Avoid blocking operations in `async` routes
    
- **Pydantic v2 Changes**:
    
    - `Config` → `model_config`
        
    - `@validator` → `@field_validator`
        
- **Form/File Uploads** → `pip install python-multipart`
    
- **Email Validation** → `pip install email-validator`
    
- Use `--reload` **only in development**
