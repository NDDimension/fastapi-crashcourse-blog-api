# 🔍 Query Parameters in FastAPI

> **In this note:** Learn how query parameters work in FastAPI — how they’re parsed, validated, documented, and when to use them vs. path parameters.

---

### 🧭 What Are Query Parameters?

- **Definition:** Key-value pairs in the URL after a `?`, separated by `&`.
    
    - Example: `/blogs?limit=10&sort=asc`
        
- **Purpose:** Used for _filtering_, _sorting_, _searching_, and _pagination_ — not for identifying a single resource.
    
- **Characteristics:**
    
    - Optional or repeatable (unlike path params)
        
    - Typically appear in `GET` requests
        

---

### 🧠 How FastAPI Binds Query Parameters

- Any **function parameter** not defined as a path parameter is read from the **query string**.
    
- **Type hints** control:
    
    - Parsing
        
    - Validation
        
    - Documentation (OpenAPI / Swagger)
        
- Supported types:  
    `int`, `float`, `bool`, `str`, `UUID`, `datetime`, `list`, etc.
    
- Use `Optional[T]` or `T | None` with a default (`None`) to make it optional.
    

---

### ✅ Typing Behavior & Examples

| Type            | Example                  | Behavior                               |
| --------------- | ------------------------ | -------------------------------------- |
| `int`           | `/blogs?limit=abc`       | ❌ → `422 Unprocessable Entity`         |
| `bool`          | `/blogs?published=false` | ✅ Parsed as `False` (case-insensitive) |
| `Optional[str]` | omitted param            | → `None`                               |
| `list[str]`     | `/items?tag=a&tag=b`     | → `['a', 'b']`                         |

**Example:**

```python
from typing import Optional
from fastapi import Query

def get_items(
    tags: list[str] = Query([]),
    limit: int = Query(10),
    published: bool = Query(True)
):
    ...
```

---

### 🧰 Validation & Metadata with `fastapi.Query`

Add constraints, docs, and metadata with the `Query()` helper:

```python
from fastapi import Query
from typing import Literal

limit: int = Query(10, ge=1, le=100, description="Items per page (1–100)")
sort: Literal["asc", "desc"] | None = Query(None, description="Sort order")
search: str | None = Query(None, min_length=1, max_length=100)
```

**Benefits:**

- Numeric constraints (`ge`, `le`)
    
- Text length limits
    
- Rich documentation (descriptions, examples)
    
- Aliases, deprecated flags, etc.
    

---

### 🧭 Path vs Query Parameters

| Use Case            | Example                          | Purpose                      |
| ------------------- | -------------------------------- | ---------------------------- |
| **Path parameter**  | `/blogs/{id}`                    | Identify a single resource   |
| **Query parameter** | `/blogs?published=true&limit=10` | Filter or shape a collection |

**Guideline:**  
Keep URLs stable, predictable, and combine both thoughtfully.

---

### ⚖️ HTTP Semantics

- `GET` with query params should be **safe** and **idempotent** (no server-side state changes).
    
- Great for **caching** — each query string variation → new cache key.
    
- **Avoid sensitive data** in query strings:
    
    - They appear in logs, browser history, and caches.
        

---

### ⚠️ Common Gotchas

- **Type mismatches** → `422` validation errors (good thing — they protect you).
    
- **Boolean parsing:** Prefer explicit `true` / `false` over ambiguous values.
    
- **Optional ≠ empty string:** `sort=None` ≠ `sort=""`.
    
- **Sets:** Not JSON-compatible; FastAPI encodes as **lists** (order not guaranteed).
    
- **Overlapping routes:**
    
    - `/blog/unpublished` vs `/blog/{id}`
        
    - Static routes take precedence, but choose clear names.

### 📚 Docs & Developer Experience

- All query parameters automatically appear in `/docs` with:
    
    - Type hints
        
    - Defaults
        
    - Descriptions
        
- Optional params show as **not required**.
    
- Defaults appear prefilled for quick testing.
